# VisionSense_Ai
VisionSense AI is a real-time AI-powered workforce monitoring system that analyzes live video streams using person detection, tracking, face recognition, pose estimation, and activity recognition to identify individuals, monitor behavior, detect anomalies, and generate actionable insights.


---

## 📌 Phase 1 

Before building the final dashboard interface, **Phase 1** focused on successfully integrating and testing the core tracking parameters. 

The tracking parameters successfully completed in this phase include:
* **Multi-Person Tracking:** Successfully identifying multiple students at once and assigning each person a permanent ID number.
* **Drowsiness Detection:** Successfully tracking eye states to flag when a student becomes sleepy.
* **Looking Away Detection:** Successfully monitoring head movements to catch when a student looks away from the front of the class.
* **Device Usage Detection:** Successfully spotting and tagging when a student is using a phone or a laptop.
* **Student Activity Tracking:** Successfully identifying when a student is actively reading or writing.
* **Data Logging:** Successfully saving all of these parameters into a history log with exact timestamps.
